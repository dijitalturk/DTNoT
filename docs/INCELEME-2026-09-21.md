## Bulgular — öncelik sırasıyla

1. **[BLOKE EDİCİ] Firefox'a kurulamıyor.** Manifest yalnız `background.service_worker` içeriyor; Firefox MV3 service worker kabul etmiyor (event page ister).
   → Düzeltme: `background: { scripts: ['…/background.js'], service_worker: '…', type: 'module' }` (DTAI Tool'da aynı düzeltme uygulandı). `@crxjs` `scripts` alanını üretmiyorsa manifest elle yazılmalı ya da paketleme adımında iki manifest üretilmeli.
2. **[KRİTİK] İzin verilmeden hiç not eklenemiyor.** `activeTab`/`tabs` izni yok → `chrome.tabs.query` URL döndürmüyor → kayıt anahtarı boş.
   Banner'ın *"Notlarınız her durumda kaydedilir"* sözü **tutulmuyor**. → `permissions`'a **`activeTab`** eklenmeli (geniş izin uyarısı çıkarmaz, ikona tıklama anında o sekmenin URL'sini verir); post-it için site izni ayrıca istenir (mevcut tasarım doğru).
3. **[ORTA] "Sayfayı aç" her zaman `https://`** varsayıyor. Anahtar protokolsüz (`host + path`) olduğu için yalnız http ile erişilen sitelerde yanlış adrese gider.
   → Şemayı da sakla ya da `https` başarısızsa `http` dene.
4. **[ORTA] JSON içe aktarma popup içinde.** Chrome'da dosya seçici açılınca popup kapanabilir (dosya seçimi iptal olur). → İçe/dışa aktarma **ayarlar sayfasına** taşınmalı (DTAI UX'i zaten ayrı ayarlar sayfası kullanıyor).
5. **[ORTA] `_locales` yok.** Mağaza adı/açıklaması (`__MSG_…__`) yerelleştirilemiyor; AMO/CWS için gerekli.
6. **[DÜŞÜK] Test yok.** `normalizeUrl` / `validateStore` / `saveNote` için birim testi şart (DTAI'de bu disiplin var).
7. **[BİLGİ] Kota hesabı:** 4000 karakter × 300 not ≈ **1,2 MB**; Chrome `storage.local` sınırı 10 MB, Firefox daha geniş → `unlimitedStorage` **gereksiz** (handoff'taki "gerekirse ekle" maddesi hesapla kapandı). Uyarı eşiği UX amaçlı kalabilir.
8. **[BİLGİ] React bundle 159 KB.** Popup bir liste + form + 3 düğmeden oluşuyor; aynı işi düz JS ~15-20 KB'de yapar (DTAI Tool'un **tamamı** ~50 KB). Karar noktası → aşağıda (A).
9. **[DÜŞÜK] İçerik betiği 1 sn'lik konum yoklaması** (`setInterval`) her sayfada dönüyor; `pushState`/`popstate` yaması zaten var → yoklama 2-3 sn'ye çıkarılabilir veya MutationObserver'a çevrilebilir.
